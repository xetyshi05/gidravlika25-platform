# Фотографии производства

Помещайте сюда фотографии цеха, оборудования, сборки и готовых гидроцилиндров.

Рекомендуемые имена: `production-01.webp`, `production-02.webp`.
Поддерживаемые форматы: `.webp`, `.jpg`, `.jpeg`, `.png`.

После добавления файлов они будут доступны по адресу
`/images/production/<имя-файла>`.
