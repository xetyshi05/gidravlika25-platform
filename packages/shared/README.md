# Shared frontend building blocks

Пакет содержит только стабильные элементы, которые действительно используются несколькими приложениями:

- `fetch-with-timeout` — общий timeout/abort helper;
- `use-modal-accessibility` — единая логика фокуса, Escape и inert для модальных окон;
- `request-contracts` — базовые типы, допустимые значения и подписи заявок;
- `assets/fonts` — общие локальные Manrope и Days One.

Специфичные для Web, CRM или Backoffice компоненты должны оставаться внутри соответствующего приложения. Новые элементы переносятся сюда только после появления реального повторного использования.
